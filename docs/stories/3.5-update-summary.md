## 🎯 Impact Analysis

### **What Changed:**
Story 3.3.1 removed Good List and EXIM Tariff from per-declaration uploads, and added support for **multiple Certificate of Origin files** (1-20 files per declaration).

### **How This Affects Story 3.5:**

**Before Story 3.3.1:**
- PDF Viewer displays 6 files: AN, BOL, CO, Invoice, Good List, Tariff
- Single C/O tab: "Certificate of Origin"

**After Story 3.3.1:**
- PDF Viewer displays 4 file types: AN, BOL, **multiple C/O**, Invoice
- Multiple C/O tabs: "C/O #1", "C/O #2", "C/O #3", etc. (dynamically generated)
- Good List/Tariff no longer displayed (system-wide knowledge bases)

### **Implementation Considerations:**

**Tab Selector UI:**
- **1-4 C/O files:** Display as individual tabs
- **5+ C/O files:** Use grouped dropdown to avoid tab overflow
- Example: "Certificate of Origin ▼" → Dropdown menu with "C/O #1", "C/O #2", ..., "C/O #10"

**Data Fetching:**
- Read Declaration `uploaded_files` JSONB structure
- Determine number of C/O files
- Fetch each C/O file: `GET /api/declarations/{id}/files/CO_1.pdf`, `CO_2.pdf`, etc.

**Backwards Compatibility:**
- Old declarations (before Story 3.3.1): Single `CO.pdf` file + Good List + Tariff (6 files total)
- New declarations (after Story 3.3.1): Multiple `CO_X.pdf` files (4 file types)
- PDF viewer must detect format and display appropriately
