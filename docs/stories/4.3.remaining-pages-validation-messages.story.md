# Story 4.3: Remaining Pages & Validation Messages

## Status
Ready for Review

## Story

**As a** Vietnamese-speaking customs processor,
**I want** all remaining application pages (upload, declarations list, companies) and all validation/status messages translated to Vietnamese,
**so that** I have a complete end-to-end Vietnamese language experience across the entire platform.

---

## Acceptance Criteria

1. **Upload page fully translated** - File upload interface, drag-drop zones, file validation messages in Vietnamese
2. **Declarations list page fully translated** - Table headers, filters, search, status badges, action buttons in Vietnamese
3. **Companies management page fully translated** - Table headers, company information, action buttons in Vietnamese
4. **Processing stages translated** - All 6 processing stages (uploaded, processing, extracting, validating, completed, failed) in Vietnamese
5. **Status labels translated** - All 7 declaration statuses with appropriate Vietnamese governmental terminology
6. **Dialog/modal messages translated** - Confirmation prompts, success/error dialogs in Vietnamese
7. **Validation warning messages translated** - All cross-document validation warnings in Vietnamese
8. **Date/number/currency formatting implemented** - Vietnamese conventions (dd/MM/yyyy, 1.234.567,89, VND)
9. **Translation completeness verified** - 100% of remaining user-facing text translated
10. **Zero functional regressions** - All existing functionality works identically in both locales

### Vietnamese Formatting Conventions
[Source: Vietnamese Locale Standards]

**Date Formatting:**
- Vietnamese: `dd/MM/yyyy` (10/11/2025 = November 10, 2025)
- English: `MM/dd/yyyy` (11/10/2025 = November 10, 2025)

**Number Formatting:**
- Vietnamese: `1.234.567,89` (period for thousands separator, comma for decimal)
- English: `1,234,567.89` (comma for thousands separator, period for decimal)

**Currency Formatting:**
- Vietnamese VND: `1.234.567 ₫` or `1.234.567 VND`
- Vietnamese USD: `1.234,56 USD` (follows Vietnamese number format)
- English VND: `₫1,234,567` or `VND 1,234,567`
- English USD: `$1,234.56`

**Implementation with next-intl:**
```typescript
import { useFormatter } from 'next-intl';

export function FormattedValues() {
  const format = useFormatter();

  // Date formatting
  const date = new Date('2025-11-10');
  const formattedDate = format.dateTime(date, {
    year: 'numeric',
    month: '2-digit',
    day: '2-digit'
  });
  // Output (vi): 10/11/2025
  // Output (en): 11/10/2025

  // Number formatting
  const number = 1234567.89;
  const formattedNumber = format.number(number, {
    minimumFractionDigits: 2,
    maximumFractionDigits: 2
  });
  // Output (vi): 1.234.567,89
  // Output (en): 1,234,567.89

  // Currency formatting (VND)
  const amountVnd = 1234567;
  const formattedVnd = format.number(amountVnd, {
    style: 'currency',
    currency: 'VND'
  });
  // Output (vi): 1.234.567 ₫
  // Output (en): ₫1,234,567

  return (
    <>
      <div>{formattedDate}</div>
      <div>{formattedNumber}</div>
      <div>{formattedVnd}</div>
    </>
  );
}
```
