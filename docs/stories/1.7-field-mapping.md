## FIELD SOURCE MAPPING

### Document Priority for Conflicting Data

When the same field appears in multiple source documents with different values, use this priority order:

1. **INVOICE** (highest priority for pricing, quantities, product descriptions)
2. **Certificate of Origin** (highest priority for origin country, CO details)
3. **Bill of Lading** (highest priority for shipping details, weights, containers)
4. **Arrival Notice** (lowest priority, used only for arrival dates and warehouse)

### Field Calculation Rules

**Fields Requiring Calculation:**

1. **`total_taxable_value_vnd`**: `invoice_total × exchange_rate` (adjusted for incoterm)
2. **`unit_price_vnd`**: `invoice_unit_price × exchange_rate`
3. **`invoice_line_total`**: `quantity_1 × invoice_unit_price`
4. **`import_duty_amount`**: `taxable_value_vnd × import_duty_rate`
5. **`vat_amount`**: `(taxable_value_vnd + import_duty_amount) × vat_rate`
6. **`total_tax_amount_vnd`**: `import_duty_amount + vat_amount`

### Fields Requiring External Lookup

1. **`hs_code`**: May require fuzzy matching against Good List (Story 2.2)
2. **`import_duty_rate`**: Lookup from EXIM-Tariff database (Story 2.4)
3. **`vat_rate`**: Lookup from EXIM-Tariff database (Story 2.4)
4. **`vat_rate_code`**: Lookup from EXIM-Tariff database (Story 2.4)
5. **`preferential_code`**: Determined by CO form type and origin country

## CONFIDENCE SCORING GUIDELINES

**Per-Field Confidence Scoring:**

Each extracted field must include a confidence score (0.0-1.0) based on:

| Confidence Level | Score Range | Criteria |
|-----------------|-------------|----------|
| High | 0.90-1.00 | Field clearly printed, no ambiguity, single source |
| Medium | 0.70-0.89 | Field readable but handwritten, or conflicts between documents resolved |
| Low | 0.50-0.69 | Field partially visible, multiple interpretations possible |
| Very Low | 0.00-0.49 | Field missing, illegible, or high uncertainty |

**Aggregate Confidence by Category:**

- **Critical Fields** (importer tax code, invoice total, HS code): Require 0.85+ confidence
- **Important Fields** (addresses, dates, quantities): Require 0.70+ confidence
- **Optional Fields** (phone, brand name, condition): Accept any confidence level

## VALIDATION RULES

**Cross-Document Validation (Story 2.3 will implement, but Story 1.7 should flag):**

1. **Invoice total vs CO total**: Should match within 1%
2. **BOL gross weight vs Invoice total weight**: Should be consistent
3. **Date sequence**: Invoice date ≤ BOL date ≤ Arrival date
4. **Container count**: BOL container count should match actual containers listed
5. **Product quantity**: INVOICE quantity should match CO quantity

**Data Type Validation:**

1. **Dates**: Must be in DD/MM/YYYY format
2. **Numbers**: Use comma for thousands separator (e.g., 23,385.2)
3. **HS Codes**: Must be exactly 8 digits
4. **Country Codes**: Must be ISO 3166-1 alpha-2 (2 characters)
5. **Currency Codes**: Must be ISO 4217 (3 characters)
