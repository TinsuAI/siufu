### Critical Vietnamese Customs Terminology
[Source: Epic + Vietnam Customs Regulations]

**IMPORTANT:** These translations require Vietnamese customs expert verification before deployment.

**Core Customs Terms:**
- **Tờ Khai** = Declaration (formal customs document)
- **Mã Số Thuế** = Tax Code (10-digit business identifier)
- **Người Nhập Khẩu** = Importer (legal entity importing goods)
- **Người Xuất Khẩu** = Exporter (legal entity exporting goods)
- **Mã HS** = HS Code (Harmonized System code for products)
- **Vận Đơn** = Bill of Lading (B/L - shipping document)
- **Chứng Nhận Xuất Xứ** = Certificate of Origin (C/O)
- **Cục Hải Quan** = Customs Office
- **Cảng Dỡ Hàng** = Port of Discharge
- **Cảng Xếp Hàng** = Port of Loading

**Tax & Duty Terms:**
- **Thuế Nhập Khẩu** = Import Duty
- **Thuế GTGT** = VAT (Thuế Giá Trị Gia Tăng - Value Added Tax)
- **Thuế Suất** = Tax Rate
- **Giá Tính Thuế** = Taxable Value
- **Số Tiền Thuế** = Tax Amount
- **Miễn Thuế** = Tax Exemption
- **Tổng Số Tiền Thuế Phí** = Total Tax Amount
- **Hạn Nộp Thuế** = Tax Payment Deadline

**Shipping & Logistics Terms:**
- **Phương Thức Vận Chuyển** = Transport Mode
- **Tên Tàu** = Vessel Name
- **Ngày Đến** = Arrival Date
- **Kho Hàng** = Warehouse
- **Kiện Hàng** = Package
- **Trọng Lượng Tổng** = Gross Weight
- **Container** = Container (same in Vietnamese)

**Financial Terms:**
- **Hóa Đơn** = Invoice
- **Số Hóa Đơn** = Invoice Number
- **Tổng Giá Trị Hóa Đơn** = Invoice Total
- **Đơn Vị Tiền Tệ** = Currency
- **Tỷ Giá Hối Đoái** = Exchange Rate
- **Điều Kiện Giao Hàng** = Incoterm
- **Phương Thức Thanh Toán** = Payment Method

**Product Terms:**
- **Hàng Hóa** = Goods/Products
- **Mô Tả Hàng Hóa** = Product Description
- **Số Lượng** = Quantity
- **Đơn Vị** = Unit
- **Đơn Giá** = Unit Price
- **Nước Xuất Xứ** = Country of Origin
- **Nhà Sản Xuất** = Manufacturer
- **Thương Hiệu** = Brand
- **Tình Trạng Hàng** = Condition (e.g., "Mới 100%" = 100% New)
- **Mã Ưu Đãi Thuế Quan** = Preferential Tariff Code
