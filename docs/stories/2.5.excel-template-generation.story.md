## Story

**As a** system,
**I want** to generate a Vietnamese customs declaration Excel file (CD.xlsx) matching the official format,
**so that** users can submit the file directly to customs without reformatting (per FR6, FR9).

---

## Acceptance Criteria

1. Excel generator uses openpyxl 3.1.5 to create .xlsx file based on template structure from `resources/sample/2/CD.xlsx`
2. Template includes: Header section (importer name, address, tax ID, declaration date), Product line items table (product description, HS code, quantity, unit price, total value, origin), Tax summary (subtotal, import duty, VAT, total payable)
3. All extracted data fields mapped to correct Excel cells
4. Number formatting matches customs requirements (currency with 2 decimals, dates as DD/MM/YYYY)
5. Vietnamese language headers and labels preserved from template
6. Generated file saved to `./data/exports/{declaration_id}/CD.xlsx`
7. File downloadable via API endpoint `GET /api/declarations/{id}/export`
8. Generated Excel file opens correctly in Microsoft Excel and LibreOffice Calc without errors
9. Manual comparison: Generated file for `sample/2/` matches structure of original `resources/sample/2/CD.xlsx`

### openpyxl Usage Examples

**Loading Template and Populating Cells:**
```python
from openpyxl import load_workbook
from openpyxl.styles import numbers

# Load template
workbook = load_workbook('resources/sample/2/CD.xlsx')
worksheet = workbook.active

# Populate header
worksheet['B5'] = draft_data['consignee']['name']
worksheet['B6'] = draft_data['consignee']['address']

# Populate product table (starting row 12)
start_row = 12
for i, product in enumerate(draft_data['products']):
    row = start_row + i
    worksheet[f'A{row}'] = product['description']
    worksheet[f'B{row}'] = product['hs_code']
    worksheet[f'C{row}'] = product['quantity']
    worksheet[f'D{row}'] = product['unit_price']
    worksheet[f'E{row}'] = product['invoice_value']

    # Apply currency format
    worksheet[f'D{row}'].number_format = numbers.FORMAT_NUMBER_COMMA_SEPARATED1  # #,##0.00
    worksheet[f'E{row}'].number_format = numbers.FORMAT_NUMBER_COMMA_SEPARATED1

# Save to export directory
output_path = f'./data/exports/{declaration_id}/CD.xlsx'
workbook.save(output_path)
```

**Date Formatting:**
```python
from datetime import datetime

# Convert ISO date string to datetime
date_str = "2025-10-22"
date_obj = datetime.fromisoformat(date_str)

# Format as DD/MM/YYYY
worksheet['B8'] = date_obj
worksheet['B8'].number_format = 'DD/MM/YYYY'
```

### Error Handling
[Source: docs/architecture/error-handling-strategy.md]

**Excel Generation Errors:**
1. **Template file not found**: Raise `FileNotFoundError` with message "Excel template not found: resources/sample/2/CD.xlsx"
2. **Missing required fields**: Raise `ValueError` with message "Missing required field in draft_data: {field_name}"
3. **Disk space error**: Catch `OSError`, update Declaration status to FAILED
4. **Permission error**: Catch `PermissionError`, update Declaration status to FAILED

**API Endpoint Errors:**
1. **File not found**: Return 404 with message "Excel file not generated yet. Current status: {status}"
2. **Unauthorized access**: Return 403 with message "Access denied to this declaration"

### Coding Standards
[Source: docs/architecture/coding-standards.md]

**Naming Conventions:**
- Service class: PascalCase (`ExcelGenerationService`)
- Methods: snake_case (`generate_cd_file`, `_map_header_section`)
- Helper methods: Prefix with underscore (`_ensure_export_directory`)

**Type Hints:**
- Use type hints for all function signatures
- Example: `def generate_cd_file(declaration_id: UUID, draft_data: dict) -> str:`
- Import: `from uuid import UUID`

**Error Handling:**
- Use structlog for logging: `logger.info(f"Generated Excel: {file_path}")`
- Catch exceptions in Celery task, update Declaration status to FAILED
- Provide user-friendly error messages in API responses

**File Paths:**
- Use pathlib for cross-platform compatibility: `from pathlib import Path`
- Example: `Path('./data/exports') / str(declaration_id) / 'CD.xlsx'`

### Security Considerations

**File Download Security:**
- Verify user authentication and authorization before download (same organization)
- Prevent path traversal attacks: Validate `declaration_id` is UUID
- Do not expose absolute file paths in API responses

**File Storage:**
- Store exports in isolated directory per declaration
- Do not allow user-controlled filenames (use fixed `CD.xlsx`)
