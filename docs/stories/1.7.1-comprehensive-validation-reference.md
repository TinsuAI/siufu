## Story

**As a** QA engineer and developer,
**I want** to extract complete and accurate validation reference data from CD.xlsx files,
**so that** I can validate our LLM extraction service produces correct results across all 77+ fields.

## Context

The current `validate_sample.py --generate-reference` flag extracts only partial data from CD.xlsx files:
- **Current**: ~47 fields extracted (header, importer, exporter, shipping, invoice, CO, packages)
- **Missing**: Products are not extracted correctly (empty array), many optional fields are null
- **Issue**: Hardcoded cell positions may not work across different CD.xlsx formats (TKN vs other formats)
- **Impact**: Cannot fully validate LLM extraction accuracy - especially for product line items

Sample 1's validation-reference.json shows:
- `"products": []` (empty - BLOCKER for product validation)
- Many fields are `null` despite data being present in CD.xlsx
- Invoice currency, package units, CO info missing
