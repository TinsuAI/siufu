# Story 3.5: PDF Viewer Component

## Status
**Done**

## Story
**As a** user,
**I want** to view source PDF documents within the review interface,
**so that** I can verify extracted data against original documents (per FR10).

## Acceptance Criteria
1. PDF viewer component built with react-pdf 9.1 library
2. Displays PDF with page navigation (previous/next buttons, page number indicator)
3. Zoom controls: Zoom in, zoom out, fit to width, fit to page
4. Search functionality to find text within PDF
5. Thumbnail sidebar showing all pages (collapsible)
6. Renders 10-page PDF within 3 seconds (per NFR2)
7. Supports viewing all 4 document PDFs: AN, BOL, CO, INVOICE
8. Tab or dropdown selector to switch between different source documents
9. Highlights or scrolls to specific location when user clicks field in declaration (Story 3.7 dependency)
10. Works in Chrome 120+, Firefox 120+, Safari 17+

## Dev Notes

### ⚠️ IMPORTANT: Story 3.3.1 Impact - Multiple C/O Files

**Updated Requirements from Story 3.3.1 (Upload Interface Updates):**

Story 3.3.1 introduces **multiple Certificate of Origin (C/O) file support**. This affects the PDF viewer implementation:

**Key Changes:**
- **Before (Story 3.3):** Single C/O file per declaration (filename: `CO.pdf`)
- **After (Story 3.3.1):** Multiple C/O files per declaration (filenames: `CO_1.pdf`, `CO_2.pdf`, `CO_3.pdf`, etc.)

**Impact on This Story:**

1. **Task 6 (Document Tab Selector) Update Required:**
   - Tab selector must support **multiple C/O tabs** (not just one "Certificate of Origin" tab)
   - Tab labels: "Arrival Notice", "Bill of Lading", "C/O #1", "C/O #2", "C/O #3", ..., "Invoice"
   - Fetch multiple C/O files from backend: `GET /api/declarations/{id}/files/CO_1.pdf`, `CO_2.pdf`, etc.
   - Handle 1-20 C/O files dynamically (read from declaration metadata)

2. **API Changes:**
   - `getPDFFile()` must handle multiple C/O filenames
   - Declaration metadata includes C/O file count and filenames in `uploaded_files` JSONB

3. **UI/UX Considerations:**
   - If 5+ C/O files: Use dropdown instead of tabs (avoid tab overflow)
   - Group C/O tabs: "Certificate of Origin ▼" → Dropdown with "C/O #1", "C/O #2", etc.

4. **Backwards Compatibility:**
   - Old declarations (Story 3.3): Single `CO.pdf` file
   - New declarations (Story 3.3.1): Multiple `CO_1.pdf`, `CO_2.pdf`, etc.
   - PDF viewer must detect format and display appropriately

**Implementation Note:**
When implementing Task 6, query the Declaration's `uploaded_files` JSONB to determine how many C/O files exist and render tabs/dropdown accordingly.

#### API Integration (from docs/architecture/api-specification.md)

**PDF File Serving Endpoint:**
```
GET /api/declarations/{id}/files/{filename}
Authorization: Bearer <token> (from httpOnly cookie)
Path Parameters:
  - id: Declaration UUID
  - filename: One of [AN.pdf, BOL.pdf, CO.pdf, INVOICE.pdf, INVOICE.jpg]

Response (200 OK):
  Content-Type: application/pdf (or image/jpeg for INVOICE.jpg)
  Body: Binary PDF/image data (Blob)

Errors:
  - 404: File not found (declaration has no such file)
  - 401/403: User not authorized to access this declaration
```

**File Storage:**
- Files stored in Docker volume at `./data/uploads/{declaration_id}/` with original filenames
- Backend serves files from this location

**TanStack Query for PDF Fetching:**
```typescript
// hooks/use-pdf-document.ts
export function usePDFDocument(declarationId: string, filename: string) {
  return useQuery({
    queryKey: ['declarations', declarationId, 'files', filename],
    queryFn: () => apiClient.getPDFFile(declarationId, filename),
    staleTime: 5 * 60 * 1000, // Cache for 5 minutes (PDFs don't change)
    cacheTime: 10 * 60 * 1000, // Keep in cache for 10 minutes
  });
}
```

#### Jump-to-Source Integration (Story 3.7 Dependency)

**Highlight Box Rendering:**
- When user clicks a field in the declaration form (Story 3.7), the form will pass `highlightBox` prop to PDFViewer
- PDFViewer must auto-navigate to the specified page
- Draw red rectangle overlay on PDF canvas at bbox coordinates: `[x, y, width, height]`
- Highlight fades after 3 seconds (CSS animation or JavaScript timeout)
- This story (3.5) prepares the API; full integration happens in Story 3.7

**Bounding Box Coordinate System:**
- Origin (0,0) is top-left corner of PDF page
- X increases to the right, Y increases downward
- Coordinates are in PDF points (1/72 inch)
- react-pdf Page component supports custom overlay rendering
